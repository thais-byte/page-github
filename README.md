# Portfólio — Thaís Silva Kurokawa

Site estático feito com HTML, CSS e JavaScript, pronto para GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo: `portfolio`).
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. No repositório, vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

O GitHub Pages disponibiliza HTTPS para o site publicado.

## Antes de publicar

- Troque `seuemail@exemplo.com` pelo seu e-mail real.
- Se quiser, adicione links para LinkedIn, GitHub, projetos e certificados.
- Se quiser colocar uma foto, ela pode ser adicionada em `assets/` e inserida no `index.html`.

## Estrutura

- `index.html` — conteúdo e estrutura
- `style.css` — design responsivo
- `script.js` — menu mobile e interações
- `assets/` — imagens e outros recursos
